# Security Policy

## Supported Versions

We release security updates for the latest major version of Driftline.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in Driftline, please report it responsibly rather than opening a public issue.

### How to Report

1. Email your findings to **[security@driftline.io](mailto:security@driftline.io)** or contact repository maintainers directly.
2. Include a detailed description of the vulnerability, steps to reproduce, and any proof-of-concept code if available.
3. We will acknowledge receipt of your report within 48 hours and provide updates as we work on a resolution.

Thank you for helping keep Driftline secure!
